记录第一次写博客（2026-02-11）

发表于 2026-02-01 更新于 2026-02-27 分类于 闲话杂谈 ， 个人感悟

2026.02.11 记录下第一次写博客 在剑平的熏陶下吧 哈哈哈哈!
说起剑平来 我想详细的写一下对他的感受；
第一次见剑平是在入职5天后 先认识了同为保定老乡的前同事子豪 后面通过子豪认识了剑平，先谈第一印象哈：”帅气” “文雅” 我很少用文雅形容一个男生的气质 这里着重说一下 并不是娘！而是从内而外的书生气质！感觉这种人学习最狠了 果然没看错。 个人感觉剑平性格是那种平静，安静的性格 不太喜欢社交 喜欢自己一个人独处，但是为了社交 不得不社交的那种感觉，不知道我猜的对不对。后续可以问问，哈哈哈哈！有一件事让我对剑平同学有了新的认知！！！
依稀记得是25年hw结束后需要去工银写一下报告，由于不熟悉攻击，随求助剑平一起去工银现场去整理报告，在工作间隙中得知剑平有写博客的习惯，随之进入博客沉浸其中，从开头2020读到了2023年，在客户现场的我眼泪就止不住的留下来，我内心收到了很大冲击，那种感受就是你读到励志文学中那些主角就在你身边的感受嘛！ 活生生的列子摆在你面前那种！ 你随着代入上帝视角来看一个网瘾少年而且是从不相关的专业，从零学习计算机知识 Java python 一步一步成长成Java大佬。再代入下自己的视角，相形见绌啊 羞愧之情 佩服之感 各种情愫使我流下了眼泪。

                                                                                                                                                                    改变是痛苦的 孤独的。

2026.02.22 初五回京后 约了很久没见的朋友聚了个餐 提及了这些年的一些感悟和理解 和对今年自身感受，围绕对人生的一些见解 为人处事方式 和未来规划畅聊很久 受益匪浅。
